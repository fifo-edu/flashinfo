Loja de Envios

Sistemas internos de uma Agência Franqueada dos Correios (AGF).

Esta página existe apenas para que o GitHub Pages tenha algo público e inofensivo para servir. Os sistemas em si não são publicados aqui — são aplicações de servidor, com acesso restrito:

  • Loja de Envios — balcão, cotação de frete, rótulos e expedição.
  • Financeiro AGF — fluxo de caixa, contas a pagar e a receber.
Documentação técnica e instruções de instalação estão no README.md do repositório.
